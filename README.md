# HPI-cpp

## （一）介绍

**HPI (High-precision integer library)**
现代轻量级跨平台 C++17 高性能任意精度整数算术库

这是一个纯自学自研的  **轻量化** 、 **高精度** 、 **高性能**  且 省内存 的 C++ 大整数库。项目完全自学原创，是我 **一名 14 岁的初中生** 耗时大约一个月，经过四代更新独立开发完成的。
你甚至可以把它当作一个 C++ 原生数据类型来使用，因其重载了几乎所有的运算符，支持 cin、cout 直接输入输出，足够自然的构造，并且还自带了大量实用工具函数！

开发历程（仅列出最突出更新）：
- v1.0：最初版本，纯竖式乘法与基础动态内存分配。运算极慢（算 2^900000 耗时约 15 秒），且长除法存在死锁问题。（当时只能算个玩具程序）
- v2.0：全面切换至 10^9 进制运算，优化内存分配与释放，耗时降至约 10 秒。
- v3.0：引入 `__restrict` 解除指针别名限制，实施裸指针优化，消除核心循环中的冗余分支，耗时降至约 2 秒。
- v4.0：实现了 Karatsuba 乘法与 Knuth Algorithm D 除法。应用零拷贝切片与边算边取模的快速幂，最终 2^900000 计算耗时稳定在 0.35 秒左右。
- v4.1（当前版本）：新增了大量工具函数，覆盖密码学与数论方面，修复部分 bug，并且为所有函数添加了双语（Doxygen）注释

## （二）软件架构

底层采用 10^9 进制（`BASE = 1000000000`），数据存储在 `std::vector<int>` 中。`data[0]` 为符号位（0 正 1 负），有效数值从 `data[1]` 开始。
运算核心函数中频繁利用 `__restrict` 裸指针和局部变量寄存器缓存，去除了内层循环中处理进位时的频繁内存读写。
在有部分复杂机制运算符重载与所有工具函数中还添加了 Doxygen 注释。标识符全部采用驼峰缩写命名法。

**泛型函数**
- 因为采用了泛型函数，一个 HPI 不止可以与另一个 HPI 对象运算，只要确保所有运算符的右边是 HPI 对象，HPI 对象可以与 C++ 原生数据类型运算并返回一个新的右值（取决于是不是运算赋值符） HPI 对象。

**乘法设计（ Karatsuba 与竖式）**
- 自动分配算法：设定 128 个 limb 为阈值。小于阈值走竖式乘法，大于则自动启用 Karatsuba 算法。
- 零拷贝切片：Karatsuba 递归中不进行数组的深拷贝，直接通过指针传递下标区间。
- 底层优化：利用 `__restrict` 裸指针和局部变量寄存器缓存，去除了内层循环中处理进位时的频繁内存读写。

**除法/取模设计（ Knuth Algorithm D ）**
- 单 limb 特化：若除数为单 limb，直接走 O(n) 线性时间复杂度的专用通道，速度极快。
- 多 limb 除法：采用带归一化（Normalization）的 Knuth 算法 D，将估商误差压制在 <= 2。直接基于裸指针进行原地乘减（In-place multiply-subtract），避免了临时对象的创建与内存二次分配。

**快速幂与模运算**
- 二进制快速幂实现。
- 模幂运算在每一步乘法后立刻取模（边算边取模），防止中间结果膨胀，确保在计算巨型指数时内存占用保持恒定。

**内存优化**
- 广泛使用 `assign`、`reserve` 和 `clear` 复用 vector 容量，减少向操作系统申请堆内存的次数。
- 为单目负号实现了右值引用重载 `operator-() &&`，配合移动语义，临时对象翻转符号时实现零深拷贝。
- Karatsuba 递归中不进行数组的深拷贝，直接通过指针传递下标区间。

**I/O设计**
- 输入/构造/赋值基于字符串，可输入理论无限长的数据。
- 输出基于 `std::setw()` 与 `std::setfill()` 函数补 0，以保持 10 进制形式的正确。

**工具函数**
- 自带大量实用工具函数，涵盖高级数学、数论、密码学、自由进制转换以及切片函数，采用高性能算法（如牛顿迭代法、扩展欧几里得算法等），且经过深度优化。

## （三）环境要求

- C++ 标准：C++17 或更高。
- 编译器：GCC 9+，Clang 10+，MSVC 2019+。
- 操作系统：跨平台（Windows / Linux / macOS）。
- 编译优化：强烈建议开启 `-O3 -march=native`。在 GCC 下，能自动向量化（SIMD）底层循环，性能会有数倍提升。

## （四）使用教程

 **安装：** 只有一个头文件 `HPI.h`，你只需要把 `HPI.h` 文件下载到你的工作目录中，然后再你的程序头部中加入一句 `#include "HPI.h"` 即可开始使用。

### （1）构造
HPI 支持三种构造方式：
- `std::string` 构造，例如 `HPI a("123456");` 你也可以传入一个字符数组的地址进行构造，但在传入空指针或空字符串时会抛出错误！像 `HPI a("00-00123456")` 也是合法的，HPI 会帮你自动去除前导 0。
- 原生整数构造，例如 `HPI a = 987654LL;`
- 默认构造为 0，例如 `HPI a;`

### （2）运算
HPI 重载了几乎所有的运算符，下面列举出所有支持的运算符：
- `=` （赋值等号）
- `+`、`-`、`*`、`/`、`%`
- `+=`、`-=`、`*=`、`/=`，`%=`
- `-` （取负）、`bool()` （使其可以直接参与逻辑运算）
- `++` （前缀）、`++` （后缀）、`--` （前缀）、`--` （后缀）
- `>`、`<`、`>=`、`<=`、`==`、`!=`

一个 HPI 完全可以与另一个 HPI 对象运算，可以像 C++ 原生数据类型一样自由的使用这些运算符，而且还可以像 C++ 原生数据类型一样支持连锁调用运算符。
不只如此，只要确保所有运算符的右边是 HPI 对象， HPI 对象还可以与 C++ 原生数据类型运算并会返回一个新的右值（取决于是不是运算赋值符） HPI 对象。

**示例：**

```
    HPI a = 10;
    HPI b = 30;
    a += b;
    a = b * 5;
```

### 乘法性能配置指南
你可以自定义库中的 `THRESHOLD` 常量（位于 `HPI.h` 源代码第 39 行）。该常量代表了 Karatsuba 算法的启动阈值，单位是 limb。

简单来说，**当两个乘数的十进制位数都大于 `THRESHOLD * 9` 时**（因为 1 个 limb 存储 9 位十进制数），库会自动从基础竖式乘法切换到更高级的 Karatsuba 算法。

通常来说，最佳阈值因设备配置而异，主要取决于 **CPU 的 L1 / L2 缓存大小** 以及 **编译器的优化等级**。缓存越大且优化等级越高（如开启 `-O3`），最佳阈值就越高；反之则越低。

**如果不想进行复杂的微调，这里有一个极简指南：**
- **如果你的设备生产于 2020 年及以后**：请保持默认阈值 `128`，这是经过实验的最佳阈值。
- **如果你的设备生产于 2020 年以前**：建议降低阈值到 `64`，以避免因老旧设备缓存过小导致的性能衰退。

### （3）I/O 流重载
通过重载 `<iostream>` 中的输入流 `std::istream` 和输出流 `std::ostream`，HPI 对象能够完全像 C++ 原生类型（如 `int`、`double`）一样，直接使用 `std::cin` 和 `std::cout` 或标准输入输出流进行输入输出。你可以直接使用 `cin >>` 读入大整数，使用 `cout <<` 打印大整数。输入时，HPI 会自动处理前导零、正负号，并验证数据的合法性，并且支持连锁调用。
**注意：不支持 std::printf() 格式化打印与 std::scanf() 格式化输入！！**

### （4）工具函数
1. 转换为 `long long` 形式：对象 `.toLL()`，函数签名：`long long toLL() const`， 获取 HPI 对象的最低18位十进制数字并转换成 `long long` 类型并返回 ，用于与 C++ 原生数据类型运算或其他用途，较高的数位将被自动截断。
2. 转换为任意进制的 `std::string` 形式：对象 `.toBaseStr(进制，大小写)`，函数签名：`std::string toBaseStr(int base = 10, bool cupperCase = false) const`， 将 HPI 对象转换为任意进制的 `std::string` 类型并返回 ，用于其他库使用或 GUI 显示，用户可以指定目标进制，也可指定超过 10 的进制字母的大小写，范围 2 <= base <= 36。
3. 获取 HPI 对象在十进制形式下的位数：对象 `.getDigits()`，函数签名：`ULL getDigits() const`
4. HPI 对象整数切片：对象 `.cutHPI(起始位置, 截取长度, 是否从低位开始)`，函数签名：`HPI cutHPI(ULL pos, ULL size, bool startFromLowDigit = false) const`，索引从 0 开始，详见 Doxygen 注释。
5. 取绝对值：对象 `.abs()`，函数签名：`HPI abs() const`，返回绝对值。
6. 幂运算：对象 `.pow(指数)`，函数签名：`HPI pow(long long exp)`，基于快速幂算法进行幂运算。
7. 带取模的幂运算：对象 `.pow(指数, 模数)`，函数签名：`HPI pow(long long exp, const HPI& mod)`，基于快速幂算法进行幂运算+取模。
8. 整数平方根：对象 `.isqrt()`，函数签名：`HPI isqrt() const`，基于牛顿迭代法计算。
9. 最大公因数：对象 `.gcd(另一个对象)`，函数签名：`HPI gcd(HPI other) const`，基于辗转相除法。
10. 最小公倍数：对象 `.lcm(另一个对象)`，函数签名：`HPI lcm(const HPI& other) const`
11. 模幂逆元：对象 `.modInv(模数)`，函数签名：`HPI modInv(const HPI& mod) const`，基于扩展欧几里得算法。
12. 判断偶数：对象 `.isEven()`，函数签名：`bool isEven() const`，为了防止用户调用 `a % 2 == 0` 导致还要跑一遍完整的除法。
13. 判断奇数：对象 `.isOdd()`，函数签名：`bool isOdd() const`，为了防止用户调用 `a % 2 == 1` 导致还要跑一遍完整的除法。

**工具函数用法详情可见 Doxygen 注释**

## （五）性能测试

**测试平台**
- 计算机：ASUS ZenBook 14（2020 年产轻薄本）

- 内存：16 GB
- 操作系统：Windows 11 企业版 21H2
- 环境状态：保持插电，开启性能模式，关闭后台进程，维持较低温度。
- 编译参数：`-O3 -march=native -std=c++17`
- 下面测试结果均取多次结果最小值

**加减法测试**
| 运算类型 | 规模大小 | 单次耗时 |
| :--- | :--- | :--- |
| 加法 | 9 位 | 0.167496 us |
| 加法 | 1,000 个 limb | 1.58479 us |
| 加法 | 100,000 个 limb | 290.532 us |

| 减法 | 1,000 个 limb | 1.04228 us |
| 减法 | 100,000 个 limb | 242.621 us |

**乘法测试（基于快速幂）**
- `2^900000`：耗时 0.1713953s（结果  **270,927**  位）
- `2^5000000`：耗时 3.4237692s（结果  **1,505,150**  位）
- `2^23333333`：耗时 34.7989968s（结果  **7,024,034**  位）

**除法与取模测试（随机 1000 位除以随机 500 位）**
- 除法：单次耗时约 0.0000258s ~ 0.0000376s
- 取模：单次耗时约 0.0000259s ~ 0.0000376s

**乘方取模测试**
- `2^900000 % 1000000007`：耗时 0.0000538s
- `2^2000000 % 1000000007`：耗时 0.0000273s
- `2^2000000 % 随机 500 位大数`：耗时 0.0004516s

*(注：上述所有运算结果均已通过 Python 交叉对比验证绝对正确)*
